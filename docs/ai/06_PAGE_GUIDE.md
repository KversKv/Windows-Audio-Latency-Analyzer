# 06 PAGE GUIDE - UI 页面指引

## 测量页

- `TestPage` 展示当前测量、有效/无效计数、有效样本统计、原始波形和会话终态；模拟结果始终明确标记。
- 保存按钮由 `TestController.can_save` 驱动：已完成、用户停止或音频错误终态下，只要至少有一条完整记录即可保存。音频故障保存的是部分会话，必须保留终态与所有已完成记录。
- 缺少 DAC/ADC 时间戳或经验证的共同时间基准时，原始绝对延迟显示为空值；UI 显示无效原因和时基限制，不得把相关峰位置显示成毫秒延迟。
- 音频/持久化线程超过有界关闭等待时，关闭事件应被忽略，避免销毁仍运行的 QThread；操作结束后用户可再次关闭。

## 诊断面板

- Software Loop、Electrical Loop 和 Acoustic Loop 各自说明观测边界，结果不进入常规历史统计。
- 对无效结果保留波形、相关质量和无效原因；当时基不可信时给出排查建议，不报告绝对延迟值。

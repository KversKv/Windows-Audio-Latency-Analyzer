# 09 WORKFLOW - 工作流程 SOP

## 流程/音频任务

1. 按根 `AGENTS.md` 读取命中模块约定和专题文档；确认修改边界与数据是否涉及 schema。
2. 先描述真实信号路径、目标测量边界、时钟来源和失败/停止路径，再修改实现。
3. 为每个外部时间戳说明来源与时间域；绝对延迟必须可追溯到经验证的共同原点或明确校准。当前 Windows WASAPI + PortAudio 19.7.0 是已审计的共同 QPC 时基；不能证明时保存原始数据并标无效。
4. 检查依赖方向、回调约束、连续流生命周期、warm-up、超时/退避、无效记录保留和模拟标记。
5. 静态核对相关离线测试与 fake backend 的显式时间域契约；真实设备验收作为独立冒烟步骤记录，不能用模拟测试替代。
6. 修改结束时按 `08_CHECKLISTS.md` 同步模块约定、音频/流程文档、持久化追溯和 UI 文案。

## 测量方法验收门槛

- 合成延迟与 fake stream 只证明算法和编排在给定模型下工作。
- 硬件精度声明前，必须通过已知物理延迟路径检查 ADC/DAC 映射、共同时间原点、时钟偏移/漂移、音频驱动版本与重复测量分布。
- 声学结果必须明确包含的路径、麦克风布置和环境；校准值要说明参考、操作步骤、适用设备、日期及误差范围。
- 遇到无界原生调用风险时，QThread 的有界等待不能视为中断成功；安全退出需保留线程/窗口对象，强制超时需进程隔离。
